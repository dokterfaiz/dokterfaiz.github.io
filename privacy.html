Kebijakan Privasi Faiz Uploader

Berlaku sejak 3 November 2026. Pengembang: Dokter Faiz. · English

Ringkasnya: Faiz Uploader adalah alat pribadi yang hanya dipakai pengembangnya sendiri untuk mengunggah file ke Google Drive miliknya. Tidak ada data pengguna lain yang dikumpulkan, disimpan, atau dibagikan.

Data Google yang diakses

Faiz Uploader meminta akses Google Drive agar dapat mengunggah file aplikasi (APK) ke folder di Google Drive milik pengembang, melihat isi folder tersebut, dan memindahkan versi lama ke Sampah.

Cara data digunakan dan disimpan

Akses hanya dipakai untuk tujuan di atas. Token akses disimpan di komputer pengembang dan tidak dikirim ke server lain. Tidak ada data yang dijual, dibagikan ke pihak ketiga, atau dipakai untuk iklan.

Penggunaan data Google

Penggunaan dan pemindahan informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

Mencabut akses

Akses dapat dicabut kapan saja melalui myaccount.google.com/permissions.

Privacy Policy (English)

Faiz Uploader is a personal tool used only by its developer, Dokter Faiz, to upload app files (APKs) to the developer's own Google Drive. It requests Google Drive access solely to upload files, list the target folder, and move older versions to the trash. Access tokens are stored only on the developer's computer. No user data is collected, sold, shared with third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: developertamvan@pm.me
